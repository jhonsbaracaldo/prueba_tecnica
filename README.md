# Proyecto Frontend - Angular

## Descripción
Este proyecto frontend está desarrollado con Angular 15. Su objetivo es interactuar con el backend para gestionar las operaciones relacionadas con `Venta`, `Producto` y `Vendedor`.

## Requisitos
- Node.js (versión 16 o superior)
- Angular CLI
